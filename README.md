# AutoJump

AutoJump brings seamless Cursor-style inline Tab completion to any text field on macOS.

## Download & Install

Download the latest release for macOS:
👉 [Latest Releases](https://github.com/ducan-ne/autojump/releases/latest)

Download `AutoJump-*.dmg`, open it, and drag `AutoJump.app` into your `Applications` folder.

### Requirements

- macOS 13+ (Ventura or later)
- Grant **Accessibility** permissions in System Settings -> Privacy & Security -> Accessibility

## Automatic Updates

AutoJump includes self-update powered by [gpui-updater](https://github.com/AprilNEA/gpui-updater).
Updates are automatically staged in the background and applied cleanly when you restart the app.
You can configure automatic updates or manually check anytime in Settings (⌘,) -> About -> Updates.
